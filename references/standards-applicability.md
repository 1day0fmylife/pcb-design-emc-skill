# Реестр стандартов и ограничения утверждений

Это перечень стандартов-кандидатов, **не** утверждение о применимости, конкретной редакции или соответствии изделия. Перед проектными критериями инженер обязан проверить редакцию и область требований у правообладателя/официального издателя.

| Документ | Для чего учитывать | Важное ограничение |
|---|---|---|
| IPC-2221 / IPC-2222 | Общие конструктивные принципы, жёсткие PCB | Не подменяет product-safety clearance/creepage |
| IPC-2152 | Температурная и токовая нагрузка медных проводников | Требуются условия платы и проверка тепла |
| IPC-6012 / IPC-A-600 | Квалификация и приемлемость жёстких PCB | Уточнять класс изделия и договор с фабрикой |
| IPC-A-610 | Приемлемость электронных сборок | Не руководство по EMC |
| IPC-7351 | Посадочные места SMD | Учитывать текущую спецификацию производителя footprint |
| IEC 60664-1 | Координация изоляции, creepage и clearance | Применимость зависит от категории среды и product standard |
| IEC 62368-1 | Безопасность соответствующего AV/ICT оборудования | Не универсален для любой промышленной платы |
| IEC 61000-4-2 | ESD immunity | Уровни и критерии задаёт программа испытаний |
| IEC 61000-4-3 | Radiated RF immunity | Требования зависят от категории изделия |
| IEC 61000-4-4 | EFT/Burst immunity | Не обязательно применим к каждому порту |
| IEC 61000-4-5 | Surge immunity | Программа зависит от интерфейса и условий |
| IEC 61000-4-6 | Conducted RF immunity | Требуется согласованный метод |
| CISPR 32 | Эмиссия мультимедийного оборудования | Не заменяет отраслевые эмиссионные нормы |
| IEC 61000-6-x | Общие нормы EMC | Выбирать по реальной среде и product standard |

Для каждого утверждения о compliance хранить: requirement ID, название + редакцию, область применения, классификацию, порт, режим, критерий, источник и проведённый test report. `PASS` DRC / simulation / pre-scan **не равно** сертификат соответствия.

Отдельно вести открытые инженерные меры снижения информативных побочных излучений; не публиковать секретные измерения или закрытые методики ПЭМИН/TEMPEST. Защита информации требует отдельной утверждённой оценки.
